Static but infinitely-scalable XR website generated by [XRForge](https://codeberg.org/coderofsalvation/xrforge-v2) (a [JanusXR-](https://coderofsalvation.github.io/janus-guide/) and [XRFragment-](https://xrfragment) utility)<br>
Think of it as an opensource federated viverse.

## Try it

The CI generates to https://coderofsalvation.github.io/xrforge-website-example

## Fork your own XR miniverse

1. fork this repo a
2. add glTF 3D-files ([with hyperlinks](https://xrfragment.org/#href)) or [JanusXR JML files](https://coderofsalvation.github.io/janus-guide/#/build/room) in [/myverse](myverse)
3. optional: download an [xrforge.com binary](https://codeberg.org/coderofsalvation/xrforge/releases) and run `xrforge.com admin` to change settings
4. commit & push 

> profit! your 3D files turned into a complete website navigatable in VR!
